OptiCarga es un proyecto de optimización logística desarrollado en Python con interfaz gráfica. Compara algoritmos como Fuerza Bruta, Voraz, Backtracking y Programación Dinámica para seleccionar paquetes y maximizar el valor transportado sin exceder la capacidad del vehículo. Incluye carga de CSV, gestión de paquetes y vehículos, visualización del estado de la flota y análisis de rendimiento para evaluar eficiencia y resultados.
