OptiCarga es un proyecto de optimización logística que compara distintos algoritmos para seleccionar paquetes y maximizar el valor transportado sin exceder la capacidad del vehículo. Incluye carga de CSV, gestión de paquetes y vehículos, visualización del estado de la flota y análisis de rendimiento para evaluar eficiencia y resultados.

Versión más moderna / portafolio:
Proyecto de optimización logística desarrollado en Python con interfaz gráfica. Compara algoritmos como Fuerza Bruta, Voraz, Backtracking y Programación Dinámica para seleccionar paquetes según capacidad y valor, con soporte para carga de CSV, gestión de vehículos y visualización de resultados y tiempos de ejecución.
